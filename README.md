# BizFlow KZ — Платформа для малого и среднего бизнеса

Готовый стартовый шаблон на **Next.js 14 (App Router) + TypeScript + Tailwind CSS**.

## Что уже работает из коробки
- **Главная страница (`/`)** — чистый поиск бизнеса по названию/коду (без маркетплейса) + быстрый переход в демо-кабинет и витрину.
- **Кабинет бизнеса (`/dashboard`)** — адаптивный интерфейс для ПК и телефона:
  - Сводка по выручке, заказам и клиентам.
  - Управление товарами/услугами (добавление, скрытие, удаление).
  - Лента заказов со сменой статусов.
  - База клиентов (автоматически пополняется при заказах).
  - Генератор прямой ссылки и QR-кода для клиентов.
  - Настройки бизнеса, Kaspi и системного промпта ИИ.
- **Клиентская витрина (`/[slug]`, например `/aigerim`)** — изолированная мобильная страница конкретного бизнеса с корзиной, имитацией оплаты Kaspi Pay и встроенным чатом с ИИ-агентом.
- **API ИИ-агента (`/api/chat`)** — если добавить `GEMINI_API_KEY` в переменные окружения, отвечает реальная модель Gemini по актуальному прайсу; без ключа работает встроенный демо-бот.
- **SQL-схема (`supabase/schema.sql`)** — готова для подключения реальной БД Supabase на следующем шаге.

## Быстрый запуск локально
```bash
npm install
npm run dev
```
Откройте [http://localhost:3000](http://localhost:3000).

## Как запустить в интернете (GitHub + Vercel)
1. Создайте новый репозиторий на GitHub и загрузите туда все файлы из этой папки.
2. Зайдите на [vercel.com](https://vercel.com) → **Add New Project** → выберите ваш репозиторий.
3. Нажмите **Deploy**. Через 1–2 минуты сайт заработает по публичной ссылке.
4. (Опционально) В настройках проекта на Vercel → **Environment Variables** добавьте `GEMINI_API_KEY`, чтобы оживить настоящего ИИ-агента.
